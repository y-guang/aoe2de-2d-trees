# 透明主图画布与点击区域

2026-10-03。用户在游戏内确认，扩大透明主图画布解决了极简树点击区域过小的问题。本报告记录当前方案，替代此前偏下留白、单叉和叠块的版本。

## 点击范围与定位

在本项目实测场景中，主图画布控制可点击范围，新增 alpha=0 区域也可以扩大该范围。这是用户确认的游戏行为，尚未通过引擎代码确定精确算法，不能据此断言所有透明像素都独立参与像素级命中判断。

src/main_image.py 的 render_main 保持普通方块的像素和大小，将主图画布等比例扩大到阴影宽度：
- 标准版：41×25 → 96×59。
- UHD：79×49 → 192×119。
- 新增区域为 RGBA (0, 0, 0, 0)。
- 主图热点固定为画布中心，与阴影中心对齐；左右边界对齐，主图比阴影多出的高度居中延伸。
- 可见方块水平、竖向都居中；奇偶像素尺寸造成的边距差最多一像素。取消此前上/下 2:1 留白。
- 故意隐藏的树桩继续生成 1×1 空主图。

PNG 的 alpha=0 映射为 -1（不绘制），SMX 保留扩大后的宽高、行边界和热点。不要裁剪透明边缘或缩减 SMX 主图画布，这会撤销点击区域修复。

## 当前倒树标记：对称 A06

Model.fallen 是必填字段，MODELS 每行显式指定 True 或 False，empty 保留默认值。八个倒树文件设为 fallen=True，由 main 直接传入绘图函数。

倒树恢复普通方块轮廓和绿色侧面，顶面使用纯黑交叉斜线：
- 两组线沿顶面两条对称斜向，以顶面中心为相位原点。
- 同一间距、同一线宽，左右及上下镜像对称；不沿文件名推断行为。
- 用整数距离栅格化，在顶面原有颜色掩码内绘制，避免线条超出轮廓。
- 普通树和倒树使用完全相同的主图尺寸、透明掩码、热点及阴影。
- 输出倒树主图与二进制的 _fallen 后缀仅用于区分构建产物。
