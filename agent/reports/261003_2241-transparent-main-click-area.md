# 透明主图画布扩大点击区域

2026-10-03。用户在游戏内确认本方案解决了极简树点击区域过小的问题。

## 结论

在本项目的实测场景中，主图画布控制可点击范围，透明区域也可以参与点击判定。仅保留小方块的紧凑主图会使点击范围过小；扩大主图画布后，即使新增区域的 alpha 为 0，也能扩大可点击范围。

这是用户确认的游戏行为，尚未通过游戏引擎代码确定精确的判定算法；不要把它解释为所有透明像素都具有独立的像素级命中判定。

## 实现

在 src/main_image.py 的 render_main 中：

- 主图画布宽度取阴影宽度，高度按原主图画布的宽高比等比例扩大，并取整到像素。
- 方块保持原有像素、颜色、大小，居中粘贴到新画布，新增空白为 RGBA (0, 0, 0, 0)。
- 热点同步增加粘贴偏移，保证方块相对游戏坐标的位置不变。
- 标准主图由 41×25 扩大到 96×59；UHD 主图由 79×49 扩大到 192×119。
- 故意隐藏的树桩继续使用 1×1 空主图，不扩大。

PNG 的 alpha=0 在 main_from_png 中映射为 -1（不绘制），SMX 仍保存扩大后的主图宽高、行边界和热点。此方案依赖保留主图画布尺寸，不需要在透明区域加入可见颜色或绘制调色盘索引 0。

## 后续维护

不要按非透明像素边界裁剪主图，也不要在 SMX 编码或优化时缩减主图画布；这样会撤销点击区域修复。阴影尺寸、可见方块面积和热点定位应继续保持现有关系。

验证：此前六项测试通过，逐像素对照确认方块内容和相对热点的位置不变；点击改善由用户在游戏内确认。本次仅补充报告和代码注释。

## 留白比例与倒树标记

后续调整：可见方块在画布内水平居中，竖向透明留白按上方约 2/3、下方约 1/3 分配。标准版上/下留白为 23/11 像素，UHD 为 47/23 像素。热点同步补偿，因此移动的是方块在画布内的位置，方块在游戏中相对阴影的位置不变；画布宽高仍为 96×59 和 192×119。

Model 使用必填的显式 fallen 字段，MODELS 每一行都指定 True 或 False（empty 保留默认值），8 个 n_tree_felled_* 文件设为 True。倒树在顶面绘制纯黑色对角叉，沿顶面透视并向内留边；标记随方块尺寸调整线宽，保持不透明轮廓和热点不变。倒树主图及二进制输出使用 _fallen 后缀，阴影复用原样式。

七项测试通过，110 个 SMX 已重新生成。build/preview_main_states.png 是从编码图层解码并映射实际调色盘的普通/倒树对照；棋盘格仅用于展示透明区域。
